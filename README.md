# Brazo robótico de 6 GDL (XK-LS5B)
Documentación de la planta del Laboratorio de Control, Ingeniería Electrónica, UMSA. Semestre II/2026.

Asignaturas: ETN-902 Sistemas de Control II, ETN-1034 Aplicación de Técnicas de Control, ETN-1000 Bases de Datos.

- `index.html`: portal web (Cloudflare Pages).
- `functions/api/repo.js`: API que lista, sube y elimina archivos de este repositorio.
- `Documentacion/`: informes, planos, datasheets y evidencias.
- `programas/`: firmware del PIC y scripts.
